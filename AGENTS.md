# AGENTS.md

Guidance for AI agents working in this repository.

## Agent skills

### Issue tracker

Issues and PRDs live as local markdown under `.scratch/<feature-slug>/` — no external tracker; PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles using the default strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `CONTEXT-MAP.md` at the root points to per-context `CONTEXT.md` files (frontend `src/`, backend `src-tauri/`). See `docs/agents/domain.md`.
